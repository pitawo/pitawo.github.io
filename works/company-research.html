企業リサーチシステム

2026-08 Python / Streamlit yfinance / Plotly Claude Code

なぜ作ったか

企業の財務を調べるとき、いちばん時間がかかるのは分析ではなく数字を集めるところでした。証券コードを入れれば直近数期の損益・貸借対照表・キャッシュフローと主要な指標が並ぶ状態にしたかったので作りました。

このツールは以前に作って手元に置いていたものを、公開にあたって直したものです。元のコードは証券コードから数値をその場で生成しているだけで、実データを取りに行く処理は1行も書かれていませんでした。

どう作ったか

データは Yahoo! Finance から yfinance 経由で取得します。5社分のスナップショットを同梱してあるので、キーの設定なしで初回から動きます。収録外の企業は証券コードを入れるとその場で取得します。

画面は「企業概要」と「財務分析」の2つ。取得層と分析・表示を分けてあるので、データ元を別のものに替えても画面はそのまま使えます。

このツールで一番手を入れたのは、グラフでも指標でもなく、取得した数字をそのまま出さないための検証でした。公開データを並べるだけだと、事実ではあるが誤解を招く数字が混ざります。

検証していること 実際に引っかかった例
非継続事業の影響 ある会社の直近期は最終利益がマイナス3,268億円。ただし事業分離を除いた継続事業ベースではプラス1兆308億円。稼ぐ力を見る指標としては後者が適切なので、そちらを使って乖離を注記する
貸借対照表の構造変化 総資産が1年で56%減った期がある。事業の分離や会計基準の変更が混ざると自己資本比率の推移を単純比較できないので、前期比 ±30% を超えた期に注記を出す
決算期の飛び 決算期を変更した会社で、変則決算の期が取得元のデータに入っていない。そのまま折れ線にすると連続して見えるため、25か月の飛びを検出して注記する

詰まった点と、直したこと

このツールで一番の山場は、機能の不具合ではなく、画面はどれも正常に描画されているのに、裏側の数字だけが壊れていたことでした。

画面はできていたのに、数字が本物ではなかった

引き継いだ状態のコードは、証券コードからその場で数値を生成して表示していました。実在する企業名の横に、実在しない財務数値が並ぶ状態です。

調べると、これは中身をごまかしていたのではなく作りかけでした。設定ファイルには取得先の URL も再試行の回数も書いてあり、キャッシュの仕組みも完成しています。ただ、外部にデータを取りに行く処理が1か所も書かれていませんでした。画面を先に作り、データ取得を後で差し込む設計で、後半に手を付けないまま止まっていたわけです。

差し替えが必要だったのは、画面が呼んでいる3つの関数だけでした。画面のコードはそのまま生かして、取得層を実装しました。

営業利益が、開示されている数字とずれていた

取得元には営業利益にあたる項目が2種類あります。片方は取得元が独自に調整した数値で、企業が実際に開示している値とは一致しません。最初はこちらを使っていました。

企業が開示している値を別のデータベースで確認して突き合わせたところ、一致するのはもう一方でした。

開示値 採用した項目 使っていた項目
会社 A 1兆7,062億円 1,706,221 1,786,410
会社 B 1,139億円 113,968 107,656

単位は百万円。同梱している5社・直近4〜5期の全 17 件で見ると、乖離は最大 7.3%でした。率としては小さく見えますが、金額の桁が大きいので会社 A では800億円以上の差になります。

銀行を入れると落ちた

ライブ取得の機能を自分で足したのに、同梱している5社でしか試していませんでした。銀行の証券コードを入れると、そのまま処理が落ちます。

銀行や保険は貸借対照表に流動／固定の区分を持ちません。流動比率などがそもそも計算できないので、必要な項目が揃っているかを取得の時点で調べ、揃わない企業は理由を添えて断るようにしました。

本番で開いたら、成長率が100倍で表示されていた

手元のテストは24件すべて通っていました。公開して自分で開いたら、売上の年平均成長率が +437.8% と出ていました。正しくは +4.4%。パーセントに直す処理が2か所に入っていたためです。

これは表示だけの問題では済みませんでした。成長を評価する処理も、100倍された値を受け取っていました。成長スコアが常に上限に張り付き、総合スコアも実態より高く出ていました（ある会社で 92.4 から 74.1 へ修正）。手元のテストは「エラーが出ないこと」しか見ていなかったので素通りしていました。

ここから学んだこと

画面が動いていることは、そこに出ている数字が正しいことを何も保証しません。このツールでは3段階でそれを踏みました。数字が生成されたものだったこと、項目の取り違えで数%ずれていたこと、単位が100倍ずれていたこと。どれも画面は正常に描画されていました。

もう1つは、やらないことを決めるほうが効いたという点です。決めたのは、投資判定を出さないこと、出典を示せない業界平均と比較しないこと、取得できない項目を仮定の係数で埋めないこと、取れなかった数字を 0 で埋めないことでした。指標をいくつか削ることになりましたが、残った数字はどこから来たか説明できます。

公開について

Streamlit Cloud で公開中です。同梱データがあるので設定なしで動きます。数値が有価証券報告書と完全に一致することは保証しておらず、投資判断には使えない旨を画面にも書いています。

Streamlit Cloud の無料枠で動かしているので、しばらくアクセスがないとアプリがスリープします。その場合は起動を促す画面が先に出ますので、ボタンを押してから立ち上がるまで、数分かかることがあります。
