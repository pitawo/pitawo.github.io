PDF 変換・結合ツール

2026-08 Python / Streamlit / PyPDF2 LibreOffice Claude Code

なぜ作ったか

PDF の細かい作業は、そのたびに変換サービスを検索して使っていました。ただ、この種のサービスはどれも手元のファイルを相手のサーバーに預けることになります。中身を見せたくない資料では使いにくくなります。

自分がやりたい操作は4つ（変換・結合・ページ番号・並べ替え）しかなかったので、その4つだけが載った画面を作りました。手元で起動すればファイルは自分のパソコンから出ません。誰でも触れる版として、同じコードを Streamlit Cloud にも置いてあります。

どう作ったか

画面は Streamlit で、PDF の操作は PyPDF2 と reportlab。Office 文書（Word / Excel / PowerPoint）の変換だけは Python のライブラリでは精度が出ないので、LibreOffice をコマンドとして呼び出して変換させています。もともとは自分だけが使っていたものを、公開するにあたって全体を見直しました。

できること

  • ファイル変換 — 画像（JPG / PNG）と Office 文書を PDF に変換
  • PDF 結合 — 複数ファイルを1つにまとめる
  • ページ番号 — 各ページの右上に「1/10」形式で付与
  • 順序変更 — アップロード後に上下ボタンで並べ替え・削除

詰まった点と、直したこと

自分しか使わないうちは1つも表に出なかった問題が、「誰でも触れる場所に置く」と決めた途端に12件出てきました。

アップロードしたファイル名が、そのまま保存先になっていた

保存先を「一時フォルダ＋アップロードされた名前」で組み立てていました。ファイル名は利用者が自由に決められるので、../ を含む名前を送ると一時フォルダの外に書き込めます。実際に試して再現しました。

ファイル名を安全な形に直す処理を1つ作り、ファイルを置く箇所すべてをそこに通しました。

2人が同時に変換すると片方が落ちる

LibreOffice は自分の設定を1つのフォルダで持っていて、同時に2つ起動すると取り合いになります。手元で1人で使う分には起きませんが、公開すると閲覧者が同じ場所を共有するので簡単に起きます。

変換のたびに専用の設定フォルダを割り当てて、取り合いが起きないようにしました。

ファイルを選んだ瞬間に画面が落ちる

パスワード付き・壊れている・中身が空、この3つのどれかを選ぶと、変換ボタンを押す前に画面が落ちていました。読み込みを試す処理に、失敗したときの受け皿が無かったためです。

読み込みを1か所にまとめて検査を通し、駄目なファイルは日本語のメッセージで断るようにしました。ライブラリが返す英語のエラーも、対処のわかる日本語に置き換えています。

そのほかに直したもの

  • 範囲外のページを指定すると中身が空の PDF ができ、そのままダウンロードできた
  • 同じ名前のファイルを2つ入れると、片方が上書きされて結合結果から消えていた
  • エラー画面に自分のパソコンのフォルダ名が出ていた

ここから学んだこと

「動く」と「他人が触っても壊れない」は別でした。自分で使っている間は、壊れる操作を無意識に避けています。壊れたファイルを選ばないし、2つ同時に変換もしません。

公開する場所に置くというのは、自分がやらない操作を全部やられる場所に置くということでした。修正12件のうち、機能を足したものは1つもありません。

公開について

Streamlit Cloud で公開中です。アカウント登録なしでその場で使えます。手元で動かす場合は LibreOffice のインストールが要ります（Office 文書を変換しないなら不要）。

Streamlit Cloud の無料枠で動かしているので、しばらくアクセスがないとアプリがスリープします。その場合は起動を促す画面が先に出ますので、ボタンを押してから立ち上がるまで、数分かかることがあります。
